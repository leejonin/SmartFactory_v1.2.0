## 목적·목표
- 목적: AGV 운반 대신 협동로봇 집기·놓기로 같은 공정을 돌렸을 때의 흐름을 보여 준다.
- 목표: 공정 씬을 복사한 새 화면(robot.html)에서 공정마다 UR5e 3대가 QR 판독이 끝난 상자 중 자기 목적지 상자만 집어 출하 컨베이어에 놓고, 상자가 컨베이어로 탑차까지 간다. 기존 공장 화면은 그대로 둔다.

## 배치(공정 기준 좌표, m)
- 메인 컨베이어는 기존과 같고, QR 스캔 게이트(x=8) 뒤에 연장 롤러 컨베이어 x 8→16.4(z=0)를 둔다.
- 로봇(받침대 높이 1.05 m):
  | 로봇 | 목적지 | 받침대 위치 | 집는 위치(x) | 출하 컨베이어 |
  |---|---|---|---|---|
  | ROBOT 01 | 도크 01 | (10.5, -1.25) | 10.5 | (10.5,-2.6) → (10.5,-7) → 탑차(25.8,-7) |
  | ROBOT 02 | 도크 02 | (16.5, -0.95) | 15.6 | (17.4, 0) → 탑차(25.8, 0) |
  | ROBOT 03 | 도크 03 | (13.0, 1.25) | 13.0 | (13,2.6) → (13,7) → 탑차(25.8,7) |
- 출하 컨베이어는 도크 개구부를 지나 탑차 안(x 25.4)까지 들어가고, 상자는 x 25.8에서 적재로 집계된다.

## 동작
1. 유입·합류·QR 판독은 SW_Browser_Logistics_001과 같다(상속).
2. 판독이 끝난 상자(waiting)는 post가 되고, 목적지 번호 = 로봇 번호다. 연장 컨베이어 0.5 m/s로 자기 로봇 집는 위치까지 가서 멈춘다(pickwait). 앞 상자와 GAP 1.5 m를 지킨다.
3. 로봇 단계와 시간(초): 집기 위로 1.0 → 하강 0.45 → 흡착 0.3 → 상승 0.45 → 출하 위로 1.3 → 내려놓기 0.45 → 해제 0.3 → 상승 0.45 → 대기 자세 0.9. 합계 5.6초.
4. 관절각은 각 단계 시작 자세에서 목표 자세로 smoothstep 보간한다. 흡착 중 상자 위치 = 정기구학 공구 끝 − 상자 반높이.
5. 출하 컨베이어 시작점에 상자가 GAP 안에 있으면 내려놓기 전 위에서 기다린다.

## 기구학
- 치수는 Universal_Robots_ROS2_Description(BSD-3)의 default_kinematics.yaml·visual_parameters.yaml·ur_macro.xacro를 옮겼다. 각 관절은 원점 변환 후 z축 회전, rpy는 R = Rz·Ry·Rx.
- 역기구학: 수치 야코비안 감쇠 최소자승(λ=0.02, 단계당 ±0.3 rad). 위치 오차 + 공구 축이 아래(-Z)를 향하는 조건(가중 0.3).
- 핵심 자세는 시작 시 한 번 계산하고, 오차가 1 mm를 넘으면 오류를 던진다.

## 표시 배율(중요)
상자(0.85 × 0.55 × 0.72 m)는 공장 화면과 같다. 실제 UR5e 도달 거리 0.85 m로는 이 상자를 컨베이어 사이로 옮길 수 없어서, 로봇을 **2.2배로 키워 표시·계산**한다(도달 거리 약 1.87 m). 관절 동작·자세는 실제 UR5e와 같지만 크기는 실물이 아니다. 화면 하단 설명에도 표시했다.

## 측정값
- 10분(seed 1·7·42): 적재 100개 이상(테스트 기준), 진행 중 40개 이하. 처리량은 상류(유입·합류·QR)가 정한다(10분 생성 약 130~137개).
- 로봇 가동률 약 28~45%.
