## 개요·용어

브라우저의 관람자가 상자의 유입, 합류, QR 식별, AGV 운반을 관찰하는 시뮬레이션이다. 유입구는 상자 시작점, 도크는 상자 인도 지점, 구간 예약은 차체와 안전 여유를 포함한 다음 이동 구간을 다른 장비가 동시에 침범하지 못하도록 관리하는 기능이다. 실제 센서·설비·물리 엔진 연결은 없다.

## 입력과 결과

`Simulation({decode, random, agvCount})`를 생성하고 `step(1/60)`으로 진행한다. decode는 상자 객체를 받아 실제 QR 픽셀에서 목적지 문자열 또는 null을 반환한다. random은 0 이상 1 미만 난수이며 테스트에서는 고정 시드를 사용한다. agvCount 기본 1, UI는 3을 지정한다. 현재 선택 범위는 주차 공간에 맞춘 1~3대다.

출력은 boxes, agvs, delivered, events, lastRead, parallelTime이다. boxes는 미인도 상자만 보관하고, 인도된 상자는 delivered에 누적한다. 이벤트는 최근 8개만 보관한다. 네 유입 위치는 (-14,0),(-8,-9),(-3,-9),(2,-9), 중앙 끝은 (8,0), AGV 인계는 (10,0), 도크는 (22,-7),(22,0),(22,7)이다. 평면 좌표는 X,Z이며 Y는 높이다. 길이 1단위는 임시 1m, 중앙 이송은 +X다.

## 메서드와 처리 관계

- `reset()`: 시간·상자·출하·장비·예약을 초기화한다. 첫 AGV는 인계 위치, 나머지는 주차 위치에서 시작한다. 공유 QR 이미지는 유지한다.
- `setAgvCount(count)`: 정수 1~3을 검증한 후 reset한다. UI에서 변경 시 초기화 안내를 표시한다.
- `spawn(inlet,destination)`: 해당 입구 주변 GAP=1.5 공간이 확보되면 식별 번호·배정 목적지를 갖는 상자를 만든다. 막혀 있으면 false다.
- `step(dt)`: 0초 초과 0.05초 이하만 허용한다. 3초 생성 시도→중앙 앞 상자 우선 이동→유입 상자 이동→도착 티켓 순 합류→AGV 갱신 순이다. blocked 생성은 선택한 입구와 목적지를 보존하고 재시도한다.
- 중앙 상자는 0.5 m/s로 이동한다. 앞 상자 및 진행 중 합류 상자의 공간을 확보한다. 인계 중 상자도 후속 상자의 간격 제한에 포함한다.
- QR 끝 위치에서 1초를 기다리고 decode를 호출한다. 유효한 세 지역이며 최초 배정과 일치할 때만 waiting 상태다. 실패·불일치는 error, `retryScan()`은 해당 상자만 scan으로 돌린다.
- `requestTravel(a,state,route)`: 장비 상태와 경유점들을 설정한다. 전역 통로 잠금은 사용하지 않는다.
- `stepAgv(dt)`: 미운반 상자가 있으면 QR 판독 전부터 경로가 짧은 빈 AGV를 선배차한다. 인계 공간이 점유되면 옆 대기 위치에 한 대를 보내고 공간이 비면 바로 진입시킨다. 복귀 중 빈 장비는 안전한 경유점에서 주차장 대신 QR로 직행한다. 인계 위치와 같은 도크의 사용자는 한 대다. 상하차는 각각 2초다. 출발 구간을 벗어나면 인계 예약을 풀고, 도크 연결 구간을 벗어나면 도크 예약을 푼다.
- `corridor(from,to)`: 수평 또는 수직 구간에 X ±0.98, Z ±0.82의 차체·여유 공간을 더한 사각형을 반환한다. 모델 크기는 1.8×1.45다. `overlaps`로 다른 장비의 예약 또는 현재 점유와 비교한다. 겹치지 않으면 동시에 진행하고, 겹치면 다음 구간 진입 전 대기한다. 기다린 시간이 긴 순서로 예약한다. 진행 중 예약은 도착 전 유지한다.
- 출하 경로는 X=16, 복귀는 X=19, 인계 접근은 X=12를 중심으로 분리한다. 복귀 경로는 Z=12를 거쳐 주차장으로 간다. 교차점은 별도 경유점으로 나눈다. 임의 장애물 회피나 최단 경로 계산은 아니다.
- `advance`: 최대 AGV_SPEED(1.2m/s)×dt만큼 목적지로 이동하며 도착 시 좌표를 정확히 맞춘다. 실제 이동 장비가 2대 이상인 프레임의 시간을 parallelTime에 누적한다.
- `encodeRegion`: qrcode 모듈에 목적지 JSON을 넣고 4모듈 여백·6픽셀 배율 RGBA 이미지를 생성한다. `decodeRegion`: jsQR 결과 JSON에서 유효 지역만 반환한다. 같은 RGBA를 상자 위 텍스처와 판독에 사용한다. 렌더된 원근 영상의 광학 인식은 아니다.
- `createScene`: WebGLRenderer, OrbitControls, 공장·표지·장비 GLB·공유 상자 자원을 만든다. `fitModel`은 장비 범위를 지정 크기로 정렬한다. `batchStatic`은 정적 트럭을 재질별로 병합한다. `load` 실패 시 기본 형상을 유지하며 상태와 콘솔에 알린다.
- 트럭 그룹은 Y축 Math.PI 회전하여 적재문을 도크 쪽으로 둔다. 도크의 X 위치를 기준으로 하역대·표지·트럭을 함께 배치한다. 원본 GLB는 변경하지 않는다.
- `sync(sim)`: 활성 상자만 장면에 유지하고 AGV 수와 좌표를 맞춘다. 상자·QR·테이프·띠 geometry와 material은 공유한다. 배송된 메시 참조는 제거한다.
- `view(name)`: 탑뷰·QR·AGV 기준 좌표를 적용하고 직접 조작을 유지한다. ResizeObserver로 크기·종횡비를 갱신한다.
- `main.js`의 frame: 경과 시간을 최대 0.1초로 제한하고 1/60초 고정 단계로 계산한다. 비활성 탭은 진행하지 않는다. UI는 약 200ms마다 갱신한다. `updateUi`는 실제 상태만 표시한다.

createScene은 하나의 바닥·외벽·렌더러 아래 buildLayer로 네 장면 그룹을 배치한다. GLB는 URL별로 한 번 로드하고 트럭 병합 결과를 공유한다. 카메라는 전체 1열 범위에 맞췄으며 QR·AGV 근접 뷰는 L1 기준이다.

### ./src/factory.js

```javascript
import { LAYERS } from './layout.js';
import { Simulation } from './simulation.js';
import { encodeRegion, decodeRegion } from './qr.js';

/** 동일 운영 로직의 네 레이어를 독립 실행하고 기존 화면에 합계를 제공한다. SW_Browser_Logistics_001 */
export class FactorySimulation {
  /** 레이어당 같은 AGV 대수를 사용하고 QR 이미지는 목적지마다 한 번 생성한다. */
  constructor({agvCount=3, random=Math.random}={}) {
    this.qrImages=LAYERS.map(layer=>layer.regions.map(encodeRegion));
    this.layers=LAYERS.map((layer,i)=>({...layer,simulation:new Simulation({agvCount,random,regions:layer.regions,
      decode:b=>decodeRegion(this.qrImages[i][layer.regions.indexOf(b.destination)],layer.regions)})}));
  }
  /** 네 레이어에 동일한 고정 시간 단계를 적용한다. */
  step(dt){for(const layer of this.layers)layer.simulation.step(dt);}
  /** 모든 레이어의 진행·집계를 초기화한다. */
  reset(){for(const layer of this.layers)layer.simulation.reset();}
  /** 모든 레이어에 같은 N대를 적용한다. */
  setAgvCount(count){for(const layer of this.layers)layer.simulation.setAgvCount(count);}
  /** 판독 실패 상자만 기존 규칙대로 다시 읽는다. */
  retryScan(){for(const layer of this.layers)layer.simulation.retryScan();}
  /** 동기 실행 중인 전체 모의 시간. */
  get time(){return this.layers[0].simulation.time;}
  /** 화면용 활성 상자 합계. 내부 상태는 각 레이어가 소유한다. */
  get boxes(){return this.layers.flatMap(layer=>layer.simulation.boxes);}
  /** L1~L4의 각 도크 순서로 나열한 12개 출하 수량. */
  get delivered(){return this.layers.flatMap(layer=>layer.simulation.delivered);}
  /** 화면에서 레이어를 구분하는 장비 상태. */
  get agvs(){return this.layers.flatMap(layer=>layer.simulation.agvs.map(a=>({...a,layer:layer.id})));}
  /** 최근 판독 결과를 레이어 이름·시각과 함께 전달한다. */
  get lastRead(){return this.layers.flatMap(layer=>layer.simulation.lastRead?[{...layer.simulation.lastRead,layer:layer.id}]:[]).sort((a,b)=>b.time-a.time)[0]||null;}
  /** 서로 같은 상자 번호라도 레이어 이름으로 구분하는 최근 기록. */
  get events(){return this.layers.flatMap(layer=>layer.simulation.events.map(e=>({...e,message:`${layer.id} · ${e.message}`}))).sort((a,b)=>b.time-a.time).slice(0,8);}
}

```

### ./src/simulation.js

```javascript
import { REGIONS } from './qr.js';

export const INLETS = [{ x: -14, z: 0 }, { x: -8, z: -9 }, { x: -3, z: -9 }, { x: 2, z: -9 }];
export const DOCKS = [{ x: 22, z: -7 }, { x: 22, z: 0 }, { x: 22, z: 7 }];
export const GAP = 1.5;
export const AGV_SPEED = 1.2; // m/s: 구간 예약을 유지한 채 이동 속도만 20% 상향.
/** 경로 위 좌표를 속도에 맞춰 이동한다. 목적지에 도착하면 true를 반환한다. */
function advance(object, target, distance) {
  const dx = target.x - object.x, dz = target.z - object.z, length = Math.hypot(dx, dz);
  if (length <= distance) { object.x = target.x; object.z = target.z; return true; }
  object.x += dx / length * distance; object.z += dz / length * distance;
  return false;
}
/** 차체 여유 폭을 포함한 직선 이동 구간의 예약 영역을 계산한다. */
function corridor(from,to=from){return {minX:Math.min(from.x,to.x)-0.98,maxX:Math.max(from.x,to.x)+0.98,minZ:Math.min(from.z,to.z)-0.82,maxZ:Math.max(from.z,to.z)+0.82};}
/** 두 예약 영역이 겹치는지 검사한다. */
function overlaps(a,b){return a.minX<b.maxX&&a.maxX>b.minX&&a.minZ<b.maxZ&&a.maxZ>b.minZ;}
/** 선택한 AGV 군과 네 유입구를 관리하는 결정적 물류 상태기계. SW_Browser_Logistics_001 */
export class Simulation {
  /** @param {{decode: Function, random?: Function, agvCount?: number, regions?: string[]}} options 레이어별 목적지와 기존 공통 운영 설정. */
  constructor({ decode, random = Math.random, agvCount = 1, regions = REGIONS }) {
    this.decode = decode; this.random = random; this.agvCount = agvCount; this.regions = [...regions]; this.reset();
  }
  /** 모든 실행 상태를 초기화한다. 외부 QR 자원은 유지한다. */
  reset() {
    this.time = 0; this.spawnClock = 0; this.nextId = 1; this.ticket = 0;
    this.boxes = []; this.pending = null; this.delivered = [0, 0, 0]; this.created = 0;
    this.events = []; this.lastRead = null;
    this.agvs = Array.from({length:this.agvCount},(_,i)=>({ id:i, x:i===0?10:7, z:i===0?0:4+i*2.6, home:{x:7,z:4+i*2.6}, state:i===0?'ready':'idle', box:null, route:[], timer:0, trips:0 }));
    this.agv = this.agvs[0]; // 기존 단일 장비 참조와 시험 호환.
    this.pickupOwner = 0; this.standbyOwner = null; this.dockOwners = [null,null,null];
    this.agvs.forEach(a=>{a.segment=null;a.waitAge=0;});this.parallelTime=0;
  }
  /** 대수를 변경할 때 진행 중인 운반과 통계를 함께 초기화한다. */
  setAgvCount(count) {
    if(!Number.isInteger(count)||count<1||count>3)throw new RangeError('현재 배치의 AGV 대수는 1~3대입니다.');
    this.agvCount=count;this.reset();
  }
  /** UI 표시용 사건을 최대 8개 보관한다. */
  log(message) { this.events.unshift({ time: this.time, message }); this.events.length = Math.min(8, this.events.length); }
  /** 선택된 입구가 비어 있을 때만 상자를 생성한다. @returns {boolean} 생성 여부 */
  spawn(inlet, destination) {
    const p = INLETS[inlet];
    if (this.boxes.some(b => b.state !== 'loaded' && Math.hypot(b.x - p.x, b.z - p.z) < GAP)) return false;
    this.boxes.push({ id: this.nextId++, inlet, destination, read: null, x: p.x, z: p.z, state: inlet === 0 ? 'main' : 'inbound', ticket: null, timer: 0 });
    this.created++; return true;
  }
  /** 판독 실패 상자만 재시도 상태로 변경한다. */
  retryScan() { for (const b of this.boxes) if (b.state === 'error') { b.state = 'scan'; b.timer = 0; } }
  /** 작은 고정 시간 간격으로 전진한다. 메인 루프와 테스트에서 동일한 함수를 사용한다. */
  step(dt) {
    if (!(dt > 0 && dt <= 0.05)) throw new RangeError('step은 0초 초과 0.05초 이하로 호출해야 합니다.');
    this.time += dt; this.spawnClock += dt;
    if (!this.pending && this.spawnClock >= 3) {
      this.spawnClock -= 3;
      this.pending = { inlet: Math.floor(this.random() * 4), destination: this.regions[Math.floor(this.random() * 3)] };
    }
    if (this.pending && this.spawn(this.pending.inlet, this.pending.destination)) this.pending = null;
    if (this.pending) this.spawnClock = Math.min(this.spawnClock, 3);

    // 앞 상자를 먼저 계산하여 후속 상자의 간격을 보존한다.
    const reserved = this.boxes.find(b => b.state === 'merge' && b.z > -GAP);
    const main = this.boxes.filter(b => !['inbound', 'merge'].includes(b.state) && (b.state !== 'loaded' || this.agvs.some(a=>a.box===b&&a.state==='loading'))).sort((a,b) => b.x-a.x);
    for (let i = 0; i < main.length; i++) {
      const b = main[i];
      if (b.state === 'main') {
        const mergeLimit = reserved && b.x < reserved.x ? reserved.x-GAP : 8;
        b.x = Math.min(8, b.x + 0.5 * dt, i ? main[i-1].x - GAP : 8, mergeLimit);
        if (b.x >= 8) { b.state = 'scan'; b.timer = 0; this.log(`#${b.id} QR 판독 시작`); }
      } else if (b.state === 'scan') {
        b.timer += dt;
        if (b.timer >= 1) {
          b.read = this.decode(b);
          if (this.regions.includes(b.read) && b.read === b.destination) {
            b.state = 'waiting'; this.lastRead = { id: b.id, destination: b.read, time: this.time };
            this.log(`#${b.id} QR 확인 · ${b.read}`);
          } else { b.state = 'error'; this.log(`#${b.id} QR 실패 · 인계 중지`); }
        }
      }
    }
    for (const b of this.boxes.filter(b => b.state === 'inbound').sort((a,b) => b.z-a.z)) {
      const ahead = this.boxes.filter(c => c !== b && c.inlet === b.inlet && ['inbound','merge'].includes(c.state) && c.z > b.z).sort((a,c) => a.z-c.z)[0];
      b.z = Math.min(-GAP, b.z + 0.5*dt, ahead ? ahead.z-GAP : -GAP);
      if (b.z >= -GAP) { b.state = 'merge'; b.ticket = this.ticket++; }
    }
    // 합류는 도착 티켓 순서이며 이동 중인 한 상자의 합류 영역을 예약한다.
    const merging = this.boxes.filter(b => b.state === 'merge').sort((a,b) => a.ticket-b.ticket);
    const first = merging[0];
    if (first) {
      const free = this.boxes.every(b => b === first || b.state === 'loaded' || Math.hypot(b.x-first.x,b.z) >= GAP);
      if (free) {
        first.z = Math.min(0, first.z+0.5*dt);
        if (first.z === 0) { first.state = 'main'; first.ticket = null; }
      }
    }
    this.stepAgv(dt);
  }
  /** 이동 경로를 설정한다. 통로 전체를 잠그지 않고 각 직선 구간을 개별 예약한다. */
  requestTravel(a,state,route) {
    a.state=state;a.route=route;a.segment=null;a.waitAge=0;
  }
  /** 주차 복귀 중인 빈 장비는 안전한 경유점에서 QR 위치로 바로 전환한다. */
  approachRoute(a) {
    if(a.state==='idle')return [{x:12,z:a.z},{x:12,z:2.5},{x:10,z:2.5},{x:10,z:0}];
    // 출하 연결선(-7,0,7)에서 역주행하지 않고 그 사이 횡단선으로 복귀한다.
    if(a.x>=19){const crossZ=a.z<=0?3.5:a.z<=7?10.5:a.z;return [{x:19,z:a.z},{x:19,z:crossZ},{x:13,z:crossZ},{x:13,z:2.5},{x:10,z:2.5},{x:10,z:0}];}
    return [{x:12,z:a.z},{x:12,z:2.5},{x:10,z:2.5},{x:10,z:0}];
  }
  /** 현재 위치부터 경유점까지의 총 이동 길이를 계산해 가까운 빈 장비를 먼저 보낸다. */
  routeLength(a,route) {
    let distance=0,previous=a;for(const p of route){distance+=Math.hypot(p.x-previous.x,p.z-previous.z);previous=p;}return distance;
  }
  /** 가까운 빈 AGV를 QR 인계 또는 바로 옆 대기 위치에 선배차한다. */

    const candidates=this.agvs.filter(a=>a.state==='idle'||(a.state==='returning'&&!a.segment))
      .map(a=>({a,route:this.approachRoute(a)}));
    if(state==='staging')candidates.forEach(c=>c.route.pop());
    candidates.sort((p,q)=>this.routeLength(p.a,p.route)-this.routeLength(q.a,q.route)||p.a.trips-q.a.trips||p.a.id-q.a.id);
    const chosen=candidates[0];if(!chosen)return;
    const direct=chosen.a.state==='returning';
    if(state==='staging')this.standbyOwner=chosen.a.id;else this.pickupOwner=chosen.a.id;
    this.requestTravel(chosen.a,state,chosen.route);
    if(direct)this.log(`AGV ${chosen.a.id+1} · QR 위치로 바로 복귀`);
  }
  /** 인계 지점·도크·통로 예약으로 다중 AGV를 배차하고 적재 상자를 차체에 결합한다. */
  stepAgv(dt) {
    const waiting=this.boxes.find(b=>b.state==='waiting');
    const hasWork=this.boxes.some(b=>b.state!=='loaded');
    if(this.pickupOwner===null&&hasWork){
      if(this.standbyOwner!==null){
        const staged=this.agvs[this.standbyOwner];
        if(staged.state==='standby'){this.pickupOwner=staged.id;this.standbyOwner=null;this.requestTravel(staged,'approaching',[{x:10,z:0}]);}
      }else this.dispatch('approaching');
    }
    const gate=this.agvs[this.pickupOwner];
    if(this.standbyOwner===null&&hasWork&&gate&&['ready','loading','outbound'].includes(gate.state))this.dispatch('staging');
    for(const a of this.agvs){
      if(a.state==='ready'){
        if(waiting&&this.dockOwners[this.regions.indexOf(waiting.read)]===null){
          a.box=waiting;waiting.state='loaded';a.state='loading';a.timer=0;
          a.dock=this.regions.indexOf(waiting.read);this.dockOwners[a.dock]=a.id;
          this.log(`#${waiting.id} AGV ${a.id+1} 인수`);
        }
      }else if(a.state==='loading'){
        a.timer+=dt;a.box.x=8+2*Math.min(1,a.timer/2);
        if(a.timer>=2){const dock=DOCKS[a.dock];this.requestTravel(a,'outbound',[{x:16,z:0},{x:16,z:dock.z},{x:19,z:dock.z},dock]);}
      }else if(a.state==='unloading'){
        a.timer+=dt;
        if(a.timer>=2){
          const b=a.box;this.delivered[a.dock]++;a.trips++;this.log(`#${b.id} ${b.read} 도크 인도 완료`);
          this.boxes=this.boxes.filter(c=>c!==b);a.box=null;
          const crossings=[0,7,12].filter(z=>z>a.z).map(z=>({x:19,z}));
          this.requestTravel(a,'returning',[{x:19,z:a.z},...crossings,{x:12,z:12},{x:12,z:a.home.z},a.home]);
        }
      }
    }
    let moving=0;
    // 진행 중 예약을 유지하고 오래 기다린 장비부터 다음 구간을 요청한다.
    for(const a of [...this.agvs].sort((a,b)=>(b.waitAge||0)-(a.waitAge||0)||a.id-b.id)){
      if(!a.route.length)continue;
      if(!a.segment){
        const proposed=corridor(a,a.route[0]);
        if(this.agvs.some(b=>b!==a&&overlaps(proposed,b.segment||corridor(b)))){a.waitAge+=dt;continue;}
        a.segment=proposed;a.waitAge=0;
      }
      const oldX=a.x,oldZ=a.z;
      if(advance(a,a.route[0],AGV_SPEED*dt)){a.route.shift();a.segment=null;}
      if(a.x!==oldX||a.z!==oldZ)moving++;
      if(a.state==='outbound'&&a.x>=16&&this.pickupOwner===a.id)this.pickupOwner=null;
      if(a.state==='returning'&&a.x<=19&&this.dockOwners[a.dock]===a.id)this.dockOwners[a.dock]=null;
      if(['approaching','staging'].includes(a.state)&&a.x<=13&&this.dockOwners[a.dock]===a.id)this.dockOwners[a.dock]=null;
      if(!a.route.length){
        if(a.state==='approaching')a.state='ready';
        else if(a.state==='staging')a.state='standby';
        else if(a.state==='outbound'){a.state='unloading';a.timer=0;}
        else a.state='idle';
      }
    }
    if(moving>=2)this.parallelTime+=dt;
    for(const a of this.agvs)if(a.box&&a.state!=='loading'){
      a.box.x=a.x+(a.state==='unloading'?1.9*Math.min(1,a.timer/2):0);a.box.z=a.z;
    }
  }
}
```

```javascript
import jsQR from 'jsqr';

export const REGIONS = ['목동', '합정동', '면목동'];
/** 목적지별 실제 QR 모듈을 RGBA 이미지로 만든다. SW_Browser_Logistics_001 */
export function encodeRegion(region) {
  const code = QRCode.create(JSON.stringify({ destination: region }), { errorCorrectionLevel: 'M' });
  const scale = 6, border = 4, width = (code.modules.size + border * 2) * scale;
  const data = new Uint8ClampedArray(width * width * 4);
  for (let y = 0; y < width; y++) for (let x = 0; x < width; x++) {
    const mx = Math.floor(x / scale) - border, my = Math.floor(y / scale) - border;
    const dark = mx >= 0 && my >= 0 && mx < code.modules.size && my < code.modules.size && code.modules.get(my, mx);
    const i = (y * width + x) * 4;
    data[i] = data[i + 1] = data[i + 2] = dark ? 10 : 255;
    data[i + 3] = 255;
  }
  return { data, width, height: width };
}
/** QR 픽셀을 판독하고 허용된 목적지만 반환한다. 실패 시 null이며 원래 배정값으로 우회하지 않는다. */
export function decodeRegion(pixels, allowedRegions = REGIONS) {
  if (!pixels) return null;
  const result = jsQR(pixels.data, pixels.width, pixels.height);
  try {
    const destination = JSON.parse(result?.data).destination;
    return allowedRegions.includes(destination) ? destination : null;
  } catch { return null; }
}
```

2. pickupRoute는 현재 구간을 끝까지 보존한다. arrivalTime은 경로 이동시간과 현재 점유의 예상 해제시간을 합한다. 멈춘 차량은 임시 4초 비용이며 정확한 미래 예측이 아니다. dispatch는 빈 주차·복귀 차량 중 추정 도착시간이 짧은 차량을 선택한다. 지정 차량의 구간 경계에서 선대기 차량이 이미 도착했거나 ETA가 1초 이상 빠르면 역할을 교환한다. 무제한 경로 탐색이나 임의 차량 교체는 아니다.

4. 이동 중 corridor는 현재 차체부터 남은 경로만 포함하도록 매 단계 축소된다. 출하 통로 X=16 회전점에는 다음 구간(turn)을 함께 확보하고 도착 시 해당 예약을 이어받는다. 다른 차량의 차체·현재 구간·회전 후 구간을 모두 검사한다.

```js
  requestTravel(a,state,route) {
    a.state=state;a.route=route;a.segment=null;a.turn=null;a.waitAge=0;
  }
  /** 빈 차량의 도크 출구를 분리하고 픽업 옆으로 직접 복귀한다. 도크 입구와 출구를 2.5m씩 분리하며 기존 컨베이어를 통과하지 않는다. */
  approachRoute(a) {
    if(a.state==='idle')return [{x:12,z:a.z},{x:12,z:2.5},{x:10,z:2.5},{x:10,z:0}];
    if(a.x>=19){const exitZ=DOCKS[a.dock].z+2.5;return [{x:22,z:exitZ},{x:13,z:exitZ},{x:13,z:2.5},{x:10,z:2.5},{x:10,z:0}];}

  }
  /** 현재 구간을 마친 뒤의 경로를 산출한다. 진행 중인 예약은 바꾸지 않는다.
   * @param {object} a 빈 AGV. @param {string} state 인계 또는 선대기.
   * @returns {object[]} 현재 구간 끝을 포함한 경유점.
   */
  pickupRoute(a,state){
    const end=a.segment?a.route[0]:null;
    const route=this.approachRoute(end?{...a,...end}:a);
    if(state==='staging')route.pop();
    return end?[end,...route]:route;
  }
  /** 경로 길이와 교차 예약의 해제 예상 시간을 합산한 도착 시간 추정값(초).
   * 정지 차량의 점유에는 4초 비용을 주며 실제 이동은 별도 충돌 검사로 보호한다.
   */
  arrivalTime(a,route){
    let eta=0,from=a;
    for(const to of route){
      const area=corridor(from,to);let delay=0;
      for(const other of this.agvs){
        if(other===a||(!overlaps(area,other.segment||corridor(other))&&!(other.turn&&overlaps(area,other.turn))))continue;
        const clear=other.segment?Math.hypot(other.x-other.route[0].x,other.z-other.route[0].z)/AGV_SPEED:4;
        delay=Math.max(delay,clear-eta);
      }
      eta+=Math.max(0,delay)+Math.hypot(to.x-from.x,to.z-from.z)/AGV_SPEED;from=to;
    }
    return eta;
  }
  /** 현재 위치부터 경유점까지의 총 이동 길이를 계산한다. 경로 비교와 검증에 사용한다. */
  routeLength(a,route) {
    let distance=0,previous=a;for(const p of route){distance+=Math.hypot(p.x-previous.x,p.z-previous.z);previous=p;}return distance;
  }
  /** 예상 도착 시간이 가장 짧은 빈 AGV를 배정하고 진행 중인 구간은 끝까지 보존한다. */
  dispatch(state) {
    const candidates=this.agvs.filter(a=>a.state==='idle'||a.state==='returning')
      .map(a=>({a,route:this.pickupRoute(a,state)}));
    candidates.sort((p,q)=>this.arrivalTime(p.a,p.route)-this.arrivalTime(q.a,q.route)||p.a.trips-q.a.trips||p.a.id-q.a.id);

    if(state==='staging')this.standbyOwner=chosen.a.id;else this.pickupOwner=chosen.a.id;
```

정적 구조물과 소품은 기존 batchStatic으로 재질별로 합친다. 같은 색은 material() 캐시, 같은 무늬·반복은 patterned() 캐시를 공유하므로 하나의 메시로 묶인다:
```js
  decor.updateMatrixWorld(true);scene.add(batchStatic(decor));
  ...
```

소품을 로드하면 모델 바닥을 y=0에 맞춘다(ClutteringD 원본은 최저점이 0.35m라 떠 있었다). 그다음 propSpots의 좌표마다 복제해 놓고 합친다. 소품 로드가 실패하면 기존 load()가 상태 문구로 알리고 나머지 장면은 그대로 동작한다.

소품 좌표(propSpots)는 AGV 경로(x=10·13·16·19·22 통로, z=dock.z·dock.z±2.5), 상자 이송 구간, 바닥 표지를 피한 자리다. 선반 줄은 z=-13.9, 고층 랙은 x=-22.4, 도크 사이 소품은 x≈23.8 + 도크 z±3.5, 작업대는 (6.5,-2.6), 수거함은 (-23.2,11.5)이다.
