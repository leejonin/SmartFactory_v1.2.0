- 목표: 표준 UNO R3 외형 + 모든 전선이 핀·구멍·잭에 꽂힘. npm test 통과.
- 환경: Three.js 0.187.0, 새 패키지 없음. 지침 ForAgents v0.1.0(4.11 코드 재사용 반영)·ForAgentsConcept v0.0.8.

## 요청
1) 보드 확대 화면 캡처와 함께 "선 연결 안 되어 있다, 수정해". 2) 표준 UNO 그림 2장과 함께 "보드를 위 이미지처럼 만들고 실제 아두이노 전선처럼 연결해".

## 원인
전선 시작점을 보드 근처 고정 월드 좌표로 정해 두어, 보드 모델의 실제 핀 위치와 맞지 않고 허공에서 끝났다. 전원 케이블도 DC 잭이 아닌 보드 옆 공중에서 시작했다. 보드는 센서 실드 일체형(Freaduino) 모델이라 표준 UNO와 모양이 달랐다.

## 변경
- ./src/conveyor/arduino.js(신규)
  - createArduinoUno(): UNO R3를 표준 치수(68.6×53.3 mm)·핀 배치(인치 좌표)로 모델링.
    - 기판 외곽 모따기, 고정 구멍 4개, 파란 기판, 실크 인쇄(DIGITAL (PWM~)·POWER·ANALOG IN·핀 라벨·로고·UNO).
    - 검정 암 헤더 4개(디지털 8+10, 전원 8, 아날로그 6)와 구멍, USB-B, DC 잭, 리셋 버튼, 크리스털, 콘덴서 2개, 레귤레이터, ATmega328P DIP-28(다리 28개), LED.
    - pin(name)은 헤더 구멍 윗면 좌표를 돌려준다(D0~D13, 5V, GND, A0~A5 등). D7(1.9")과 D8(1.74") 사이 0.16" 어긋남을 반영했다.
  - createBreadboard(): 400구 브레드보드(82.5×54.5×8.5 mm, 30열 × a~j, 위·아래 ±레일, 6열마다 레일 구멍 빔). hole(col,row)는 구멍 윗면 좌표.
- ./src/conveyor/kit.js
  - 보드 GLB(uno.glb) 대신 createArduinoUno() 사용. 스페이서를 UNO 고정 구멍 위치로 옮김. 보드 옆에 브레드보드 배치.
  - 배선을 실제 조립 방식으로 바꿈. 점퍼선 양 끝의 검정 플러그를 헤더·브레드보드 구멍 위에 꽂고, 전선은 플러그 윗면에서 나간다.
    - 전원: 5V·GND → 위 레일, 위·아래 레일 연결.
    - 서보·근접센서·컬러센서: 케이블 커넥터를 브레드보드 g행에 꽂고, G·V는 아래 레일, 신호는 아두이노 핀(노랑 서보 D9, 초록 서보 D10, 근접센서 D2, 컬러센서 A4 SDA·A5 SCL).
    - 모터 드라이버: VCC·GND는 위 레일, IA ← D5, IB ← D6. 나사 단자에서 모터로 감.
    - 배럴 플러그는 DC 잭 입구에 끝까지 꽂힌 상태에서 스위치로 감.
  - 기존 bundle()에 starts 인자를 더해 재사용(전선마다 실제 시작점에서 8mm 올라온 뒤 묶음 경로). 점퍼선은 jumper(), 꽂기는 plugAt()·deviceConnector().
  - 로딩 부품 수 6 → 5(보드는 직접 모델링).
- ./src/conveyor/main.js: 구성 부품 목록에 UNO R3·브레드보드·L9110S·사용 핀 표기. 앱 v0.0.21(두 화면 하단·package.json·package-lock.json).
- ./Asset/kit-parts/uno.glb는 더 이상 쓰지 않는다(삭제는 하지 않음, 빌드에도 포함되지 않음).
