## 동작
상자는 3.6초마다 입구에 올라간다(앞 상자가 0.16 m 이상 떨어졌을 때만). 벨트는 4.5 cm/s다. x=0.22 m에서 적외선 근접센서가 감지 표시를 켜고, x=0.29 m 컬러센서 아래에서 0.25초 판독한다. 판독 결과가 노랑·초록이면 해당 서보 팔이 상자가 오기 전에 벨트 위로 48° 들어온다. 상자는 팔 면을 따라 옆으로 밀려 벨트 가장자리를 넘으면 0.5초 포물선으로 같은 색 상자에 떨어진다. 빨강은 게이트 없이 벨트 끝(x=L)에서 빨강 상자로 떨어진다. 상자가 떨어지면 게이트는 쉬는 자세(벨트 가장자리를 따라 입구 쪽)로 돌아간다.

```js
export function armDirection(gate, k) {
  const heading = Math.PI + gate.side * KIT.armAngle * k;
  return { x: Math.cos(heading), z: Math.sin(heading) };
}
```
k=0이면 팔이 -x(입구 쪽)를 향해 벨트 밖에 있고, k=1이면 side 방향에 따라 벨트 위로 armAngle(0.84 rad)만큼 들어온다.

팔과 상자의 접촉(pushByArm): 팔 상류 쪽 법선 n 방향 거리가 상자 반폭보다 작으면, 그만큼 n 방향으로 밀어 낸다. 벨트는 계속 +x로 밀기 때문에 결과적으로 상자는 팔 면을 따라 옆으로 미끄러진다.
```js
    const n = -d.z < 0 ? { x: -d.z, z: d.x } : { x: d.z, z: -d.x };
    const rx = cube.x - gate.x, rz = cube.z - gate.z, along = rx * d.x + rz * d.z, dist = rx * n.x + rz * n.z;
    if (along < -KIT.half || along > KIT.armLength + KIT.half) return;
    if (dist < KIT.half && dist > -KIT.half * 2) { cube.x += (KIT.half - dist) * n.x; cube.z += (KIT.half - dist) * n.z; }
```
게이트는 "판독된 자기 색 상자가 팔 끝(tip) 5 cm 앞 ~ 피벗 사이"에 있을 때만 작동한다. 투입 간격(0.16 m)이 팔이 덮는 x 범위보다 커서 앞 상자를 잘못 밀지 않는다(테스트로 확인).

## 3D 구성(추정 치수, m)
벨트 길이 L=0.56, 폭 0.07, 윗면 높이 0.1. 롤러 반지름 0.0115(벨트 두께 0.0015 포함 0.013), 축 높이 0.0865. 끝단 측판(주황 PLA)은 ExtrudeGeometry로 롤러 머리·다리·608 베어링 구멍(22 mm)을 그린다. 벨트는 윗면·아랫면·양 끝 반원을 하나의 띠로 만들고 u 좌표를 진행 거리로 두어, 텍스처 offset만 움직여도 벨트가 도는 것처럼 보인다. 분류 상자는 0.1 m 아크릴(반투명 PhysicalMaterial), 블록은 25 mm 모서리 둥근 정육면체다. PLA 부품은 적층 줄무늬 범프 맵을 쓴다. 조명은 RoomEnvironment 반사 + 그림자 있는 주광이다.

실측 부품(FreeCAD-library → GLB): 아두이노 UNO 호환 보드(Freaduino, 부품별 색 유지, PCB만 파랑으로), SG90 서보·혼, 원통형 근접센서(노랑으로 재채색), 608 베어링, 2020 알루미늄 프로파일(길이만 늘려 3개 배치). 서보·혼은 모델 최상단 정점의 중심(topCenter)을 출력축으로 보고 팔 피벗에 맞춘다.

## 조작
왼쪽 드래그 이동, 휠 확대, 오른쪽 드래그 회전(공장 화면과 같음). 시점: 전체·센서·분류 게이트·제어 보드. 일시정지·초기화·속도 1/2/4배. 상단 "← 공장 전체"로 돌아간다.

## 제한
- 키트 치수·센서 모델명은 사진 기준 추정이다(판매 페이지는 작업 환경에서 열리지 않음). 실제 키트 조립 후 치수 비교 필요.
- 컬러센서 하우징·주황 프레임·분류 팔·모터는 직접 모델링했다(공개된 같은 키트의 원본 STL을 찾지 못함).
- 실제 아두이노와 연결하지 않는 시뮬레이션이다. 판독 RGB 값은 색별 대표값에 잡음을 더한 표시용 값이다.
